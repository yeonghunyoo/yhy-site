# 3단계 · 레터 보내기 모달

로그인한 방문자만 보낼 수 있고, 한 통이 Resend로 내 메일함에 도착하면서 D1에도 남는다.

## 흐름

1. 연락 섹션 "레터 보내기" 클릭 → 비로그인이면 로그인 시트 먼저, 완료 후 자동으로 레터 시트 열림
2. 필드: 제목(선택, 80자), 본문(필수, 2,000자), 답장 받을 이메일(로그인 이메일 기본값, 수정 가능)
3. `POST /api/letters` → 서버에서 세션 확인 → 제한 검사 → D1 `letters` insert → Resend 발송 (`reply_to` = 방문자 이메일)
4. 성공 토스트 "전달됐어요" → 시트 닫힘. 실패 시 본문은 유지하고 에러만 표시

## 제한·방어

| 항목 | 값 |
| --- | --- |
| 유저당 | 하루 3통 — 최근 24시간 기준 (D1 count로 검사) |
| 본문 길이 | 2,000자, 링크 5개 이하 |
| 중복 | 직전 레터와 본문 동일하면 거부 |
| 미발송 대비 | Resend 실패 시 D1에는 `status = failed`로 남기고 어드민에서 재전송 |

## 메일 형식

제목 `[Letter] {제목 또는 본문 첫 40자}`, 본문에 발신자 이메일·가입 방식(magic/google)·발송 시각·어드민 링크 포함. 발신 주소는 `letters@{도메인}`, 수신은 내 개인 메일(환경변수 `LETTER_TO`).

## UX 디테일

- 본문 입력 중 글자 수 카운터
- 작성 중 시트를 닫으면 `localStorage`에 임시 저장, 다시 열 때 복원
- 전송 버튼은 본문 10자 이상일 때 활성화
- 시트 하단에 "로그인 이메일과 내용이 저장됩니다" 한 줄 고지

## 상세 설계 (확정)

**첨부**: 불허. 본문에 링크로 대체. 링크는 5개까지, `http(s)://`만 허용하고 메일 템플릿에서는 자동 링크화하지 않는다(피싱 방지).

**도착 알림**: `POST /api/letters` 성공 직후 Telegram 봇으로 메시지 1건 — 발신자 이메일 앞 3자 마스킹, 제목, 본문 첫 80자, 어드민 링크. Telegram 호출 실패는 레터 처리에 영향 없음(`waitUntil`로 비동기).

**답장 (사이트 안에서)**

1. 어드민 레터 상세에서 답장 폼(본문 2,000자) → `POST /api/admin/letters/{id}/reply`
2. 서버: 관리자 세션 확인 → D1 `letter_replies` insert → Resend 발송(수신 `reply_to`, 발신 `letters@{도메인}`, `reply_to` = 내 개인 메일) → `letters.status = replied`
3. 방문자는 메일로 받는다. 메일 본문에 원문 인용 + 내 답장. 방문자가 메일에 답하면 내 개인 메일로 온다(그 뒤는 메일 스레드)
4. 사이트에서 이어지는 대화(스레드 UI)는 만들지 않는다 — 답장 1회가 사이트의 역할

**레터 상태**: `sent` → `read`(어드민에서 열람) → `replied`. `failed`는 Resend 전달 실패. 어드민 목록 필터는 이 4개.

**내 레터 보기 (방문자, 2차)**: 아바타 메뉴 → 보낸 레터와 답장 여부만 보이는 간단 목록. MVP에서는 제외.

## 구현 메모 (10/29)

- API: `POST /api/letters` (`src/pages/api/letters.ts`), 제한값은 `src/lib/letters.ts`에서 서버·시트가 같이 쓴다
- 응답 코드: 비로그인 401(→ 로그인 시트 + `pendingAction`), 차단 403, 형식 400(`invalid`/`links`), 중복 409, 한도 429
- `letters.locale`(ko/en)을 저장해 답장 메일 언어를 고른다
- Resend 실패 시 방문자에게는 성공으로 보인다(레터는 저장됐고 `status = failed`로 남아 어드민에서 재전송). 실패는 Telegram `⚠️ Resend 실패`
- 링크 검사: `scheme://` 형태를 모두 세어 5개 이하, 그리고 http(s)만 허용

## 완료 기준

- 모바일에서 레터 작성→전송→내 메일 도착까지 한 번에 된다
- 하루 3통 초과 시 거부 안내, 실패 건이 D1에 남는다
