# 4단계 · 어드민 대시보드

`/admin`은 SSR이며, 세션 이메일이 `ADMIN_EMAILS`에 없으면 404로 응답한다(존재 자체를 숨김). 1인 운영 전제로 화면 3개만 둔다. 여기까지가 MVP다.

## 화면

| 화면 | 경로 | 내용 |
| --- | --- | --- |
| 레터 | `/admin/letters` | 최신순 목록, 읽음 표시, 상세에서 사이트 내 답장 폼, 실패 건 재전송 버튼 |
| 사용자 | `/admin/users` | 가입일·방식·마지막 로그인, 차단 토글(차단 시 레터·챗 불가) |
| 지표 | `/admin` | 가입자 수, 최근 7일 일별 레터 수·로그인 수, (2차) 챗 질문 수 |

**2차 추가**: `/admin/chat` — 질문 로그만 보기(답변 제외). 어떤 질문이 들어오는지가 RAG 문서 보강의 근거가 된다.

## 구현

Astro SSR 페이지 + `middleware.ts`에서 `/admin` 접두 경로 가드. 차트는 일별 숫자 14개 이하라 SVG 막대 직접 그림(라이브러리 없음). 모바일에서도 열리게 테이블은 카드형으로 접힘.

## 상세 설계 (확정)

**레터 화면 (`/admin/letters`)**

- 목록: 상태 필터 칩(전체 / 안 읽음 / 답장함 / 실패), 최신순, 행당 발신자·제목·첫 줄·시각·상태
- 상세(`/admin/letters/{id}`): 열면 `read_at` 기록. 원문 + 답장 폼(2,000자) + 보내기. 답장 후 아래에 답장 내용과 시각 표시. `failed` 건은 "재전송" 버튼
- 모바일: 목록은 카드, 상세는 풀폭, 답장 폼은 하단 고정 입력창

**알림 (Telegram 봇)**

| 이벤트 | 메시지 |
| --- | --- |
| 새 레터 | `📮 새 레터` + 발신자(마스킹) + 제목 + 첫 80자 + 어드민 링크 |
| 레터 전달 실패 | `⚠️ Resend 실패` + 레터 id + 에러 요약 |
| 계정 삭제 | `🗑 계정 삭제 1건` (식별 정보 없음) |
| 5xx 발생 | `🔥 5xx` + 경로 + 에러 메시지 앞 120자 (1분에 1회로 묶음, KV 키로 중복 억제) |
| 챗 월 상한 도달 (2차) | `💸 챗 상한 도달` |

구현: `lib/notify.ts` 함수 하나, `https://api.telegram.org/bot{TOKEN}/sendMessage`. 모든 호출은 `ctx.waitUntil`로 응답과 분리. 실패는 무시.

**모니터링**: Cloudflare 기본 로그(Workers 로그·observability)만 사용. 5xx는 `middleware.ts`의 try/catch에서 잡아 Telegram으로 보내고 500 응답. 외부 서비스 추가 없음. MVP 공개 후 에러량 보고 Sentry 도입 여부 재판단.

**사용자 화면 추가 사항**: 삭제된 계정은 목록에 없음(하드 삭제). 차단 토글 시 해당 유저의 세션 전부 삭제 → 즉시 로그아웃 효과.

## 완료 기준 (= MVP 완료)

- 관리자 로그인 후 레터 읽음·답장·재전송, 사용자 차단이 모바일에서 동작
- 비관리자는 `/admin`에서 404를 본다
