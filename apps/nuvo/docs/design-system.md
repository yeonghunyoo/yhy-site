# nuvo 디자인 시스템

**원칙: 사진이 주인공이고, UI는 조용하게.**

- 색 수를 줄입니다. 따뜻한 무채색 6단계와 강조색 1개, 경고색 1개만 씁니다.
- 눈부심을 줄입니다. 순수 검정(#000)과 순수 흰색(#fff)을 쓰지 않고, 채도가 아주 낮은 웜톤으로 대체합니다.
- 강조색은 아낍니다. 주요 버튼, 선택 상태, 진행 막대, 사진 속 일부 입자에만 씁니다.
- 앱 안의 `/design` 페이지에서 두 테마를 나란히 보고, 대비를 실시간으로 확인할 수 있습니다.

## 색 토큰

값은 OKLCH이고 정의는 `apps/web/src/index.css`에 있습니다. Tailwind에서는 `bg-bg`, `text-muted`, `border-line`처럼 씁니다.

| 토큰 | 용도 | 밝은 테마 | 대비* | 어두운 테마 | 대비* |
|---|---|---|---|---|---|
| `--bg` | 페이지 배경 | `oklch(0.972 0.006 85)` #f8f5f1 | – | `oklch(0.19 0.006 70)` #161311 | – |
| `--surface` | 카드, 버튼 hover, 패널 | `oklch(0.99 0.004 85)` | – | `oklch(0.225 0.007 70)` | – |
| `--line` | 테두리, 구분선 | `oklch(0.89 0.008 80)` | – | `oklch(0.30 0.008 70)` | – |
| `--text` | 본문, 제목 | `oklch(0.27 0.01 70)` | 13.9 | `oklch(0.90 0.01 80)` | 13.7 |
| `--muted` | 보조 설명 | `oklch(0.48 0.01 70)` | 6.0 | `oklch(0.72 0.01 75)` | 7.4 |
| `--faint` | 날짜, 개수 등 부가 정보 | `oklch(0.545 0.01 70)` | 4.6 | `oklch(0.62 0.01 75)` | 5.1 |
| `--accent` | 강조 (기본: 클레이) | `oklch(0.545 0.095 45)` | 4.7 | `oklch(0.75 0.075 55)` | 8.2 |
| `--danger` | 삭제, 오류 | `oklch(0.54 0.12 25)` | 5.0 | `oklch(0.71 0.10 25)` | 6.9 |
| `--stage` | 사진 보기 배경 | `oklch(0.16 0.004 70)` | – | `oklch(0.14 0.004 70)` | – |

\* 배경(`--bg`) 대비 WCAG 명도 대비. 모든 글자색이 AA 기준(4.5:1) 이상입니다.

**강조색 후보**는 설정 화면이나 `/design`에서 바꿔 볼 수 있습니다.

| 후보 | 밝은 테마 | 어두운 테마 | 느낌 |
|---|---|---|---|
| 클레이 (기본) | `oklch(0.545 0.095 45)` | `oklch(0.75 0.075 55)` | 따뜻함, 사진·종이 느낌 |
| 세이지 | `oklch(0.53 0.065 150)` | `oklch(0.76 0.055 150)` | 차분함, 자연 |
| 슬레이트 | `oklch(0.52 0.075 255)` | `oklch(0.75 0.055 250)` | 차가움, 정돈 |

**사진 보기 화면(`--stage`)은 두 테마 모두 어둡습니다.** 밝은 배경은 사진의 명암과 색을 다르게 보이게 하기 때문입니다.

## 테마 전환

- 기본값은 **시스템 설정**을 따릅니다. 헤더 아이콘을 누를 때마다 시스템 → 밝게 → 어둡게로 바뀌고, 설정 화면에서도 고를 수 있습니다.
- `localStorage`의 `nuvo-theme`와 `nuvo-accent`에 저장합니다.
- 첫 화면이 그려지기 전에 `index.html`의 인라인 스크립트가 `<html data-theme>`을 넣어서, 깜빡임이 없습니다.
- 토큰은 `[data-theme]` 속성 선택자로 정의합니다. 그래서 어떤 요소든 `data-theme="dark"`를 주면 그 안쪽만 어두운 테마가 됩니다 (`/design` 페이지가 이 방식).

## 타이포그래피

- 글꼴은 **Pretendard Variable**이고, 필요한 글자만 내려받는 dynamic subset을 씁니다.
- 제목은 `font-light`에 `tracking-tight`, 본문은 기본 굵기 14px입니다.
- 로고 `nuvo`는 `font-light`에 넓은 자간(`tracking-[0.25em]`)을 씁니다.
- 어두운 테마에서는 아주 얇은 굵기(extralight)를 본문에 쓰지 않습니다 (번져 보임).

## 모양과 간격

- 버튼은 둥근 알약 모양(`rounded-full`)이고 높이는 32·36px 두 가지입니다.
- 카드와 대화상자는 `rounded-2xl`, 테두리 1px `--line`에 그림자는 최소로 둡니다.
- 사진 그리드 간격은 3px입니다. 사진끼리 거의 붙여서 한 장의 벽처럼 보이게 합니다.
- 아이콘은 1.5px 선 아이콘 하나의 세트로 통일합니다 (`components/icons.tsx`).

## 인터랙션과 3D

| 요소 | 내용 | 강등 조건 |
|---|---|---|
| 랜딩 입자 셰이더 | 흩어진 점 5천 개가 사진 틀 6개로 모인다. 마우스 근처 점은 밀려난다 | WebGL2 없음 → CSS 사진 틀. 동작 줄이기 설정 → 정지 상태. 저사양 → 점 1,800개 |
| 3D 시간 터널 | 최신 240장을 나선 벽에 배치. 스크롤·드래그로 과거로 이동 | WebGL2 없음이나 동작 줄이기 설정 → 3D 버튼 숨김 |
| 썸네일 | blurhash 흐린 미리보기 → 실제 사진 페이드인 | – |
| 선택 | 선택한 칸이 살짝 작아지고 모서리가 둥글어짐 | – |

**3D 구현 규칙** (실제로 겪은 문제에서 나온 규칙):
- 색은 CSS 토큰에서 읽습니다 (`readToken` → `cssColorToRgb`).
  - three.js 장면 색은 `setRGB(r, g, b, THREE.SRGBColorSpace)`로 넣습니다. 그냥 넣으면 linear 값으로 해석돼서 회색으로 떠 보입니다.
- **재질(material)과 uniform은 직접 만들어 `material={...}`로 넘기고, 바꿀 때는 객체를 직접 고칩니다.**
  - 지금 쓰는 React 19.3과 R3F 9.8 조합에서는, 마운트 뒤 JSX로 재질 prop을 바꾸면 화면에 반영되지 않았습니다.
  - 그래서 셰이더 애니메이션이 멈추고, 3D 썸네일이 회색으로만 보였습니다.
- 사용이 끝난 geometry, material, texture는 `dispose()` 합니다.

## 접근성

- 모든 글자색이 배경 대비 4.5:1 이상입니다.
- 포커스 링은 강조색 2px입니다 (`:focus-visible`).
- `prefers-reduced-motion`이면 전환 효과와 셰이더 애니메이션을 끕니다.
- 대화상자는 네이티브 `<dialog>`를 씁니다. 포커스 가두기와 Esc 닫기를 브라우저가 처리합니다.
- 사진 보기 단축키: ← → 이동, Esc 닫기, i 정보
