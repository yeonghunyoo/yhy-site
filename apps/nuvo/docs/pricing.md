# 구독 가격 — 손익분기와 타 서비스 비교

2026-11-04 작성. 상태: **계산 중** — 단가·경쟁 가격은 조사 결과를 채운 뒤 확정합니다.
결제 구조(앱 스토어만, 두 스토어 같은 가격)는 [service-plan.md](service-plan.md) "결제 구조".

## 1. 정해진 조건

- 상품: 개인 **10GB** 월 구독 하나. 가족은 구독 없이 Space 보기([service-plan.md](service-plan.md) 기능 구분)
- 결제: iOS IAP·Google Play 결제만. **두 스토어 같은 가격**(11/04 결정)
- 수수료: 두 스토어 모두 **15%**(소규모 사업자 프로그램 / 연 100만 달러 이하). 한국 Billing Choice(2026-12-31~)로 Android가 낮아질 수 있지만 보수적으로 15%로 계산
- 부가세: 스토어 표시 가격은 부가세 포함. 개발자가 받는 돈은 (표시 가격 − 부가세) × 0.85 — 조사(C)에서 확인
- 원가 통화는 달러, 환율은 **1달러 = 1,400원**으로 가정(바뀌면 아래 표를 다시 계산)

실제로는 구독자가 10GB를 다 채우지 않습니다. 평균 사용률을 **60%**로 가정한 v₆₀도 같이 봅니다.

### 수입 (구독자 1명당, 월)
```
표시 가격 P (원, 부가세 포함)
공급가 = P / 1.1
개발자 수취 r = 공급가 × 0.85
```

### 손익분기 구독자 수
```
N* = F / (r − v)
```
F·v는 원으로 바꿔서 계산(× 1,400).

비교에서 볼 것:
- 대형 서비스는 **용량 단가**로는 이길 수 없습니다(iCloud 50GB·Google One 100GB가 월 1천 원대). nuvo의 10GB는 용량이 아니라 **"가족이 구독 없이 함께 보는 공간"**을 파는 것입니다. 가격은 용량 단가가 아니라 가족 앨범 앱(FamilyAlbum 등 월 수천 원대)과 비교합니다
- 무료 용량: 대형 서비스가 5~30GB를 무료로 주는데 nuvo는 0GB. 그래서 "백업"으로 팔면 불리하고, "공유"로 팔아야 합니다
