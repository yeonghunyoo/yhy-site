# 플랫폼별 규칙 — 웹과 모바일

2026-11-04 작성. 상태: **제안**. 각 항목의 "제안"은 정해지기 전까지의 기본값이고, `[ ]`가 정할 것입니다.
목표는 [service-plan.md](service-plan.md), 지금 코드는 [mvp.md](mvp.md)에 있습니다.

## 원칙: 서버 규칙은 하나, 기기 동작은 플랫폼마다

- **서버가 지키는 규칙은 플랫폼과 상관없이 같습니다.**
  - 업로드 검증: R2 sha256 검증, 업로드 영수증(HMAC)
  - 허용 형식(`SUPPORTED_MIME`)과 파일 크기(100MB)
  - 용량: 개인 10GB 구독, 지금 코드는 2·5·8GB
  - 권한과 서명 URL 만료
  - 앱이라고 해서 서버 검증을 건너뛰는 경로를 만들지 않습니다.
- **플랫폼마다 다른 것은 기기 쪽 동작입니다.** 기기 사진을 어떻게 읽는지, 언제 올리는지, 받은 파일을 어디에 저장하는지가 여기에 해당합니다.
- **nuvo는 기기의 원본 파일을 지우지 않습니다.** PC 폴더와 휴대폰 사진첩 모두 같습니다(지금 규칙: mvp.md "알려진 한계"). 예외를 둘지는 아래 "삭제"에서 정합니다.

## 플랫폼 구분

| 이름 | 무엇 | 기기 사진 읽기 |
|---|---|---|
| **웹 PC** | Chrome·Edge 데스크톱 | 폴더 핸들(`showDirectoryPicker`), 다시 열어도 유지 |
| **웹 기타** | Safari·Firefox 데스크톱, 휴대폰 브라우저 | 폴더나 파일을 그때 골라 한 번 스캔(`webkitdirectory`, 파일 선택). 다시 열면 또 골라야 함 |
| **iOS 앱** | 네이티브로 감싼 앱 ([service-plan.md](service-plan.md) "모바일") | 사진 보관함(PhotoKit). 전체 또는 "선택한 사진만" 권한 |
| **Android 앱** | 같음 | 미디어 저장소(MediaStore). 사진·동영상 읽기 권한 |

## 1. 기기 사진 보기

| | 웹 PC | 웹 기타 | 모바일 앱 |
|---|---|---|---|
| 현재 | 구현됨 | 1회 스캔 | 없음 |
| 제안 | 그대로 | 그대로. 보기는 되지만 "계속 보기"는 웹 PC나 앱을 안내 | 사진첩 전체를 nuvo 타임라인에 표시. 썸네일은 OS가 주는 것을 씀(직접 디코딩 안 함) |
| 인덱스 저장 | IndexedDB | IndexedDB(세션 한정 의미) | 앱 저장소(SQLite 등) |

- [ ] iOS "선택한 사진만" 권한일 때 화면: 선택한 사진만 보여주고 권한 넓히기를 안내 (제안)
- [ ] iCloud에만 있고 기기에 원본이 없는 사진: 썸네일만 보여주고, 열 때 내려받기 (제안). 해시 계산은 원본이 있을 때만 함

## 2. 업로드 (구독자)

| | 웹 PC·웹 기타 | 모바일 앱 |
|---|---|---|
| 시작 | 사용자가 골라서 올림 (지금) | 골라서 올리기 + **자동 백업**(선택) |
| 형식 | 원본 그대로. 브라우저가 HEIC를 JPEG로 바꿔 넘기면 바뀐 파일이 올라감(iOS Safari, developer-guide 17단계 확인 필요) | **원본 그대로**(HEIC는 HEIC). 앱은 원본을 직접 읽을 수 있음 |
| 동시 업로드 | 3개 (`queue.ts`) | 제안: 3개, 셀룰러에서는 1개 |
| 네트워크 | 상관없음 | 제안: 자동 백업은 Wi-Fi에서만(기본값), 설정에서 셀룰러 허용 |
| 백그라운드 | 탭을 닫으면 멈춤. 다시 열면 이어서 | OS가 허락하는 범위(iOS 백그라운드 전송, Android WorkManager). 끊기면 다음 실행 때 이어서 |
| 용량 초과(507) | 남은 업로드 모두 멈춤 (지금) | 같음. 자동 백업은 멈추고 알림 |

- [ ] 자동 백업 대상: 사진첩 전체 / 고른 앨범만 / 설정한 날짜 이후만
- [ ] 자동 백업 기본값: 꺼짐 (제안. 구독 직후 한 번 묻기)
- [ ] 저전력 모드·배터리 부족일 때 멈춤 (제안: 멈춤)
- [ ] 웹 iOS Safari에서 HEIC가 JPEG로 바뀌는 경우: 안내 문구만 / 막기. 실기기 확인 뒤 정함

## 3. 다운로드

| | 웹 | 모바일 앱 |
|---|---|---|
| 한 장 | 원본 받기 링크(`/m/...&dl=파일이름`, 지금) | 기기 사진첩에 저장 (원본 형식, 촬영 정보 유지) |
| 여러 장 | 없음 | 없음 |
| 형식 | 원본 그대로 | 원본 그대로 |

- [ ] 여러 장 받기 (웹): 하나씩 연속으로 받기 / zip으로 묶기. zip은 Worker에서 만들면 CPU·메모리 한도에 걸리니 브라우저에서 묶는 방식을 제안
- [ ] HEIC를 못 여는 기기(Windows 기본 뷰어 등)를 위한 JPEG로 받기: 브라우저에서 변환해 받기(제안) / 지원 안 함
- [ ] 구독 해지 뒤 내려받기 기간 ([service-plan.md](service-plan.md) "정할 것"과 함께)
- [ ] Space 사진 받기 권한: 모든 멤버(지금) / 역할로 제한

## 4. 동영상

세부는 [roadmap-video-classification.md](roadmap-video-classification.md) "동영상 세부 결정".

| | 웹 PC | 웹 기타 | 모바일 앱 |
|---|---|---|---|
| 기기 동영상 보기 | 폴더 스캔에 포함, 브라우저로 재생 | 1회 스캔에 포함 | 사진첩 동영상을 OS 플레이어나 앱 플레이어로 재생 |
| 공유용 사본 만들기 | 브라우저 인코더(WebCodecs) | 브라우저 인코더. Safari 지원 범위는 실기기 확인 | **OS 기본 인코더**(iOS AVFoundation, Android Media3). 웹뷰 인코딩보다 빠르고 배터리를 덜 씀 |
| 업로드 | 사본만, 단일 업로드 | 같음 | 같음. 자동 백업에서 동영상을 따로 켜고 끔 |

- [ ] 자동 백업에 동영상 포함 기본값: 꺼짐 (제안. 용량을 빨리 채움)
