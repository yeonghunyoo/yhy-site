# nuvo 서비스 계획

2026-11-04 재조정. **MVP 목표(무료 사용량 안에서 운영)는 무효**이고, 이 문서가 nuvo의 목표 기준입니다.
지금 코드가 무엇을 하는지는 [mvp.md](mvp.md)(현재 구현 기록)에, 웹·모바일별 업로드·다운로드 등 규칙은 [platform-policy.md](platform-policy.md)에 있습니다. 둘이 다르면 이 문서가 목표, mvp.md가 현재 상태입니다.

## 목표 (11/04 결정)

- **실제 서비스로 운영합니다.** 무료 사용량 안에 맞추는 것이 목표가 아닙니다. 비용은 구독 수입으로 감당합니다.
- **핵심은 내 기기의 사진을 nuvo에서 보는 것입니다.** PC와 휴대폰에 있는 사진을 올리지 않고 그대로 봅니다. 이 기능은 서버 저장 비용이 들지 않습니다.
- **클라우드 저장은 선택 구독입니다.** 원하는 사람만 구독해서 **개인당 10GB**를 씁니다.
- **모바일은 네이티브 앱으로 감쌉니다.** 휴대폰 사진첩은 웹에서 계속 읽을 수 없어서 앱이 필요합니다(아래 "모바일").

## 기능 구분

| 구분 | 무엇 | 서버 비용 |
|---|---|---|
| 기본 (구독 없이) | 이 PC 폴더 보기, 휴대폰 사진첩 보기, 기기 안 중복 찾기·정리 제안, 기기 안 분류 | 거의 없음 (로그인·API 요청 정도) |
| 구독 | nuvo 클라우드 10GB: 백업, 다른 기기에서 보기, Space 공유 | R2 저장·요청, DB |

**잠정 (11/04): 구독 없이는 로컬 보기만, 클라우드 10GB는 구독자만.** 이 기준으로 진행하고 세부 정책은 나중에 바꿀 수 있습니다. 로그인 필요 여부, 체험 용량, Space 참여 범위는 아래 "정할 것"입니다.

## 용량과 원가

- 개인 10GB는 R2 저장 원가로 한 달 약 0.15달러입니다(무료 10GB를 넘는 분 GB당 월 0.015달러, 전송료 없음). 요청 수 비용은 별도로 작습니다.
- 계정의 R2 무료 10GB는 구독자 한 명이면 찹니다. **유료 서비스로 가려면 nuvo를 자기 Cloudflare 계정으로 옮기는 것이 먼저**입니다(루트 [`docs/monorepo.md`](../../../docs/monorepo.md) "Cloudflare·Resend 계정"). 지금은 portfolio-web과 계정을 같이 써서 8GB 상한을 코드로 걸어 두었습니다(mvp.md "계정 공용 한도").
- Workers는 실서비스라면 유료 플랜(월 5달러)을 기준으로 잡습니다. 무료 플랜은 하루 요청 수와 요청당 CPU 시간 제한이 있습니다.
- Neon(Postgres)은 사용자가 늘면 무료 한도를 넘습니다. 플랜과 비용은 출시 전에 확인합니다.
- 예전 유료 플랜 후보(Space 단위 100GB, 월 3,900원)는 무효입니다. 용량은 **사람 단위**로 묶습니다.

## 모바일

휴대폰 사진첩(iOS 사진 보관함, Android 미디어 저장소)은 웹 브라우저가 계속 읽을 수 없습니다. 사진을 그때그때 고르는 것만 됩니다. 그래서 휴대폰 사진첩 보기는 네이티브 앱으로만 됩니다.

| 방식 | 장점 | 단점 |
|---|---|---|
| **Capacitor** (지금 React SPA를 앱으로 감싸고, 사진첩 접근만 네이티브 플러그인) | 화면·타임라인·중복 정리·API 코드를 그대로 씀 | 수만 장 그리드 스크롤 성능을 확인해야 함. 썸네일은 웹 디코딩 대신 네이티브 API로 받아야 함 |
| **Expo / React Native** | 사진첩 라이브러리가 성숙하고 스크롤이 빠름 | 화면을 다시 만들어야 함. 공유 가능한 건 API 타입·로직(`@nuvo/shared`) 정도 |

- 제안: 화면을 그대로 쓰는 Capacitor로 시작하고, 실기기에서 스크롤·썸네일 성능이 부족하면 그 화면만 네이티브로 바꿉니다. 정할 것에 남깁니다.
- 지금 기기 간 "같은 사진" 판정은 파일 전체 sha256입니다. 휴대폰에서는 다음이 걸립니다. 앱 설계 때 판정 기준을 따로 정합니다.
  - 사진첩 전체를 해시하면 배터리와 시간이 많이 듭니다.
  - iCloud "저장 공간 최적화"를 켜면 원본이 기기에 없습니다.
  - PC로 옮기면서 HEIC가 JPEG로 바뀌면 같은 사진이어도 해시가 다릅니다.
- 결제(11/04 조사, [media-security.md](media-security.md) 3.4·4.5): **iOS는 웹 구독만으로는 안 되고 앱 안 IAP를 함께 팔아야 합니다**(3.1.3(b)). Android는 앱이 로그인만 하는 소비 전용이 허용됩니다. 스토어 정책은 2025~2026에 계속 바뀌고 있어 출시 시점에 다시 확인합니다.
- 스토어 심사가 요구하는 기능([media-security.md](media-security.md) 6절): 사진 신고·멤버 차단·공개 연락처·약관 동의, iOS Sign in with Apple, Android 웹 계정 삭제 페이지. 앱 전에 웹에 먼저 넣어 둡니다.

## PC

- 지금처럼 웹(Chrome·Edge 데스크톱)의 폴더 접근으로 봅니다. Safari·Firefox는 열 때마다 폴더를 다시 골라야 합니다(mvp.md "알려진 한계").
- 데스크톱 앱(Tauri)은 웹으로 부족한 점이 확인되면 그때 정합니다.

## 결제와 출시 전 할 일 (사람)

- 정기결제 수단: 국내 PG의 정기결제(빌링) 또는 스토어 결제. 정할 것입니다.
- 유료 서비스에 필요한 것: 사업자등록·통신판매업 신고, 이용약관의 결제·해지·환불(청약철회) 조항, 개인정보처리방침([developer-guide.md](developer-guide.md) 14단계)에 결제 정보 추가.
- 구독이 끝났을 때 저장된 사진을 어떻게 할지(읽기 전용 기간, 내려받기 기간, 삭제 시점)를 약관에 적습니다.

## 순서 제안

| 순서 | 내용 |
|---|---|
| 1 | nuvo를 자기 Cloudflare·Resend 계정으로 옮기기 (유료 운영의 전제) |
| 2 | 용량 모델 바꾸기: 개인 10GB, 구독 상태에 따라 업로드 허용. 서비스 전체 8GB 상한은 계정을 옮긴 뒤 비용 알림으로 바꿈 |
| 3 | 결제 연동과 약관 |
| 4 | 모바일 앱: 사진첩 보기 (구독 없이) → 구독자 백업 |
| 5 | 동영상·자동 분류 ([roadmap-video-classification.md](roadmap-video-classification.md)) |

## 정할 것

- [ ] 구독 가격 (원가: 10GB 저장 월 약 0.15달러 + 플랜·DB 고정비)
- [ ] 구독 없는 사람의 무료 클라우드 용량: 잠정 0 (11/04) / 작은 체험 용량
- [ ] Space 용량을 누구 몫으로 셀지: Space 소유자의 10GB / 올린 사람 각자의 10GB / Space 별도
- [ ] 구독 없이 Space에 참여(보기·올리기)할 수 있는지
- [ ] 결제 수단: 웹 PG 정기결제 + iOS IAP(필수) + Android는 1차 소비 전용 (제안, media-security.md 3.4·4.5)
- [ ] 모바일 감싸는 방식: Capacitor(제안) / Expo
- [ ] 기기 간 같은 사진 판정 기준 (휴대폰 해시 비용, iCloud 최적화, HEIC→JPEG 변환)
- [ ] 구독 해지 후 사진 보관 정책
