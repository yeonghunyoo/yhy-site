## 경험 수준 표기

유영훈의 기술 경험은 두 가지로 나눠 적는다. 실무는 회사 업무로 써 본 것, 개인 프로젝트는 직접 만든 서비스(handoff-agent, Forest, nuvo, 이 사이트)에서 써 본 것이다.

## 실무

- Swift · iOS 네이티브 — 트립에이드(헬미닥), 홀리츠(Let's Bee 클락, MyCONECT), (주)알파이글루
- RxSwift, Fastlane — iOS 실무
- Flutter · Dart — 홀리츠 Let's Bee 필리핀 음식 배달 서비스(유저·파트너 앱)
- 사내 에이전트 · RAG 파이프라인 — 클러쉬(주) 반도체사 파견(챗 에이전트, RAG 데이터 파이프라인 고도화)

## 개인 프로젝트

- SwiftUI · Kotlin(Jetpack Compose) — Forest iOS · Android 네이티브 동시 개발
- Python — handoff-agent의 MCP 서버
- TypeScript — 이 사이트, nuvo
- Cloudflare Workers · D1 · R2 · KV, Hono — Forest 백엔드, nuvo, 이 사이트
- Astro, React, Tailwind CSS — 이 사이트, nuvo(React Three Fiber 포함)
- 에이전트 · RAG — 이 사이트의 포트폴리오 챗(Workers AI, Vectorize)

## 이 포트폴리오에 쓴 기술

- Astro 7 — 정적 우선 사이트, 동적 경로만 서버 렌더
- React 19 — 레터·챗 아일랜드, 관리자 로그인
- Tailwind CSS v4 — 디자인 토큰을 CSS 변수로
- Cloudflare Workers, D1, KV, R2 — 호스팅·DB·레이트리밋·이미지
- Workers AI, Vectorize — 포트폴리오 챗(RAG)
- Better Auth — 관리자 이메일 매직링크와 Google 로그인
- Resend, Telegram 봇 — 메일 발송과 운영 알림
